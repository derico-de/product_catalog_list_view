This module adds a compact list view to the product catalog that is used to
add products to sale orders, purchase orders, invoices and other documents.

The default catalog only offers a kanban view whose cards show a product
image and take a lot of space. With a large product range the list view fits
many more products on one screen while keeping the catalog behavior:

- clicking a row adds the product to the order,
- the quantity can be changed directly in the row,
- the price and the "Back to ..." button work exactly like in the kanban
  catalog.

For sale orders the catalog opens in the list view by default; the kanban
view stays available through the view switcher.
