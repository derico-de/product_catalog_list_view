Product Catalog Compact List

See more products, add them faster.

Why this module?

The product catalog used to add products to sale orders, purchase orders and invoices only offers a kanban view. Its cards show a product image and take a lot of space. With a large product range you spend more time scrolling than selecting.

This module adds a compact list view to the catalog. It fits many more products on one screen while keeping the full catalog behavior:

  • Clicking a row adds the product to the order.
  • The quantity can be changed directly in the row (+ / - buttons or direct input).
  • Price display and the Back to Quotation/Order button work exactly like in the kanban catalog.

The compact list view

For sale orders the catalog opens in the list view by default; the kanban view stays available through the view switcher.

The standard kanban catalog stays available

On other documents (purchase orders, invoices, ...) the catalog still opens in the kanban view and the list view is offered in the view switcher.

Usage

  1. Open a sale order and click Catalog above the order lines. The catalog opens as a list.
  2. Click a row to add the product to the order, or use the Add button.
  3. Adjust the quantity with the + / - buttons or by typing in the quantity field.
  4. Use the view switcher in the top right corner to change back to the kanban view.
  5. Click Back to Quotation to return to the order.

Technical notes

  • The list view reuses the catalog kanban machinery, so core and third-party patches (purchase, account, mrp, ...) keep working in the list view.
  • To make the list view the default on another model, override action_add_from_catalog on that model and move the list entry of action["views"] to the front.
  • No new models, no stored fields — the module only adds a view and extends the catalog action.
