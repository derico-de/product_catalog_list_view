1. Open a sale order and click *Catalog* above the order lines. The catalog
   opens as a list.
2. Click a row to add the product to the order, or use the *Add* button.
3. Adjust the quantity with the *+* / *-* buttons or by typing in the
   quantity field.
4. Use the view switcher in the top right corner to change back to the
   kanban view. On purchase orders and invoices the catalog still opens in
   the kanban view; the list view is available in the view switcher.
5. Click *Back to Quotation* to return to the order.
